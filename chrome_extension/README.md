# SATWidget GP Updater (расширение Chrome)

Периодически (по умолчанию раз в 2 часа) скачивает GP-данные и отправляет их
Python-приложению SATWidget, которое записывает их в `data/gp.json`.

Расширение работает в **обычной сессии Chrome** (не через debug-порт), поэтому
обходит проблему `HTTP 403`, из-за которой не работал модуль `chrome_cdp.py`.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (Developer mode).
3. Нажмите «Загрузить распакованное расширение» (Load unpacked).
4. Выберите эту папку (`chrome_extension`).

## Авторизация Space-Track

Если вы уже вошли на [space-track.org](https://www.space-track.org) в этом
Chrome — расширение автоматически использует cookies активной сессии, пароли
нигде не хранятся. Если вход не выполнен — Space-Track вернёт ошибку, и при
источнике «both» расширение переключится на публичный CelesTrak.

## Настройка

Нажмите на иконку расширения, чтобы открыть настройки:

- **Порт приёмника SATWidget** — порт, на котором Python-приложение слушает
  входящие GP-данные (по умолчанию `9090`; должен совпадать с настройкой
  приложения).
- **Интервал (мин)** — как часто качать данные (по умолчанию `120`).
- **Источник данных** — Space-Track / CelesTrak / оба.

Изменение интервала автоматически переустанавливает расписание (`chrome.alarms`).

## Обновление данных на лету

Как только приёмник записывает новый `data/gp.json`, Python-приложение
немедленно (не дожидаясь таймера 5 минут):
- пересобирает модели спутников из новых GP-данных;
- записывает запись в **историю орбит** (`data/orbit_history.json`);
- обновляет виджет и показывает уведомление «GP-данные обновлены расширением».

## Проверка

Работа расширения логируется в консоли service worker:
`chrome://extensions` → «Сервисный воркер» (inspect views) → консоль.

Ожидаемые сообщения:

```
[SATWidget GP Updater] Space-Track: 12000 записей
[SATWidget GP Updater] Отправлено 12000 записей на порт 9090
```

## Файлы

- `manifest.json` — манифест MV3 (alarms, storage, host_permissions).
- `background.js` — расписание, загрузка GP, отправка в приёмник.
- `options.html` / `options.js` — страница настроек.
- `icons/` — иконки 16/48/128.
