# SATWidget GP Updater (расширение Chrome)

Расширение скачивает GP-данные **только по запросу виджета**: виджет проверяет
свежесть `data/gp.json` (критерий `tle.update_hours` в `config.json`, по
умолчанию 2 часа) и, если данные устарели, выставляет флаг `needs_update` в
своём HTTP-приёмнике. Расширение опрашивает виджет (`GET /status`) и скачивает
данные, когда этот флаг установлен. Скачанные GP-данные отправляются в виджет
(`POST /gp`), который записывает их в `data/gp.json`.

Расширение работает в **обычной сессии Chrome** (не через debug-порт), поэтому
обходит проблему `HTTP 403`, из-за которой не работал модуль `chrome_cdp.py`.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (Developer mode).
3. Нажмите «Загрузить распакованное расширение» (Load unpacked).
4. Выберите эту папку (`chrome_extension`).

## Авторизация Space-Track

Расширение использует cookies активной сессии Chrome. Если сессия потеряна
(например, после перезагрузки компьютера), расширение выполняет вход напрямую:

1. Получает страницу входа и извлекает CSRF-токен.
2. Отправляет `POST /auth/login` с логином/паролем.
3. Повторяет запрос GP-данных.

Логин/пароль берутся **из виджета**: укажите их в `config.json` приложения в
секции `space_track` (`username`/`password`). Виджет передаёт их расширению в
`GET /status` только когда данные устарели (`needs_update=true`), но не чаще
одного раза в минуту. Расширение **не хранит** учётные данные в своём
хранилище — они существуют в памяти только на время выполнения обновления.

## Настройка

Нажмите на иконку расширения, чтобы открыть настройки:

- **Порт приёмника SATWidget** — порт, на котором Python-виджет слушает
  запросы статуса и принимает GP-данные (по умолчанию `9090`; должен совпадать
  с настройкой приложения).
- **Опрос виджета (мин)** — как часто спрашивать виджет, нужны ли свежие
  данные (по умолчанию `1`).
- **Источник данных** — Space-Track / CelesTrak / оба.

Изменение интервала автоматически переустанавливает расписание (`chrome.alarms`).

## Обновление данных на лету

Как только приёмник записывает новый `data/gp.json`, Python-приложение
немедленно (не дожидаясь таймера 5 минут):
- пересобирает модели спутников из новых GP-данных;
- записывает запись в **историю орбит** (`data/orbit_history.json`);
- обновляет виджет и показывает уведомление «GP-данные обновлены расширением».

## Проверка

Работа расширения логируется в консоли service worker:
`chrome://extensions` → «Сервисный воркер» (inspect views) → консоль.

Ожидаемые сообщения:

```
[SATWidget GP Updater] Виджет: needs_update=true, cache=data/gp.json, exists=true
[SATWidget GP Updater] Виджет запросил обновление — скачиваю GP...
[SATWidget GP Updater] Space-Track: 12000 записей
[SATWidget GP Updater] Отправлено 12000 записей на порт 9090
```

## Файлы

- `manifest.json` — манифест MV3 (alarms, storage, host_permissions).
- `background.js` — опрос виджета, загрузка GP по запросу, вход на space-track.org, отправка в приёмник.
- `options.html` / `options.js` — страница настроек.
- `icons/` — иконки 16/48/128.
